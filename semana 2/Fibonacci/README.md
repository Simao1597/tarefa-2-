Fibonacci — Little Man Computer (LMC)

O programa gera a sequência de Fibonacci a partir da quantidade de termos informada pelo usuário.

Primeiro, o programa recebe o valor de n e apresenta os dois primeiros termos da sequência, 0 e 1. Em seguida, dentro do loop, soma fib_2 e fib_1 para obter o próximo termo. Os valores são atualizados e o processo continua até atingir a quantidade de termos determinada pelo usuário.

Fluxograma

O fluxograma representa visualmente o funcionamento do programa: entrada do número → apresentação dos primeiros termos → cálculo do próximo termo → atualização dos valores → verificação da condição → repetição ou finalização.
