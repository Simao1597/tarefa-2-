Contador Progressivo — Little Man Computer (LMC)

O programa realiza uma contagem progressiva de 0 até 20, aumentando o valor em 1 a cada repetição.

O programa começa carregando o valor de prim, que inicialmente é 0, e exibe esse valor. Depois, adiciona 1 e armazena o resultado em temp. Esse valor é comparado com o limite 21. Enquanto o resultado for menor que 21, o novo valor é carregado e o processo se repete.

Quando o contador chega ao limite, o programa é encerrado.

 Fluxograma

O fluxograma representa visualmente o funcionamento do programa: início → carregar o valor inicial → exibir o número → adicionar 1 → armazenar o novo valor → verificar o limite → repetir ou finalizar.
