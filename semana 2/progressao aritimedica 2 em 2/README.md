Progressão Aritmética de 2 em 2 — Little Man Computer (LMC)


O programa gera uma progressão aritmética de 2 em 2. Primeiro, o usuário informa a quantidade de termos que deseja visualizar. O programa começa com pos = 0 e, a cada repetição, acrescenta 2 ao valor anterior.

Por exemplo, se o usuário informar 5, o programa exibirá:

0 → 2 → 4 → 6 → 8

A variável n controla a quantidade de termos, enquanto pos armazena o valor atual da sequência.

 Fluxograma

O fluxograma representa visualmente o funcionamento do programa: entrada da quantidade de termos → iniciar a posição em 0 → exibir o valor → adicionar 2 → atualizar a posição → diminuir o contador → verificar se deve continuar → repetir ou finalizar.
