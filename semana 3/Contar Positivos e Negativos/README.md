Contar Positivos e Negativos — Little Man Computer (LMC)


O programa conta quantos números positivos e quantos números negativos foram digitados pelo usuário. A entrada continua até que o usuário digite 0, que indica o fim da série.

Cada número é analisado:

Se for positivo, a variável positivos aumenta em 1.
Se for negativo, a variável negativos aumenta em 1.
Se for 0, o programa encerra e mostra as duas quantidades.
 Exemplo

Se o usuário digitar:

5
-3
8
-7
2
-4
0

O programa identifica:

Positivos: 5, 8 e 2 → 3

Negativos: -3, -7 e -4 → 3

Resultado:

3
3
 Fluxograma

O fluxograma representa visualmente o funcionamento do programa: início → entrada de um número → verificar se é 0 → verificar se é positivo ou negativo → aumentar o contador correspondente → solicitar outro número → repetir → exibir as quantidades → fim.
| Execução | Positivos | Negativos | Resultado |
| -------- | --------: | --------: | --------- |
| 1        |         3 |         3 | **3 / 3** |
| 2        |         4 |         3 | **4 / 3** |
| 3        |         4 |         4 | **4 / 4** |
