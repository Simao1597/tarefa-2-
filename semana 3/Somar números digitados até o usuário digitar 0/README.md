Soma de Números até 0 — Little Man Computer (LMC)

O programa realiza a soma de vários números digitados pelo usuário. A entrada continua até que o usuário digite 0, que funciona como o valor de parada.

Cada número digitado é armazenado na variável num e acrescentado ao valor armazenado em soma. Quando o usuário digita 0, o programa encerra a repetição e exibe o resultado da soma.

 Exemplo

Se o usuário digitar:

5 → 8 → 3 → 0

O resultado será:

16

 Fluxograma

O fluxograma representa visualmente o funcionamento do programa: início → entrada de um número → verificar se é 0 → se não for, adicionar à soma → solicitar outro número → repetir → se for 0, exibir a soma → fim.

Execuçao:

| Teste | Números digitados | Resultado |
| ----- | ----------------- | --------: |
| 1     | 5, 8, 3, 0        |    **16** |
| 2     | 10, 20, 5, 0      |    **35** |
| 3     | 7, 4, 9, 0        |    **20** |
